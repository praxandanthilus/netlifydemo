# What is Minecraft? {#concept_what_is_minecraft .concept}

Minecraft is a sandbox game about placing blocks, exploring, and surviving in procedurally generated worlds.

Minecraft drops you into a blocky world made of voxels. You mine resources, craft tools, build structures, and can choose how much danger you want from hostile creatures.

## Two common editions { .section}

-   Java Edition runs on Windows, macOS, and Linux. It has the largest mod ecosystem and receives snapshots for upcoming features.
-   Bedrock Edition runs on consoles, mobile devices, and Windows \(often via the Microsoft Store\). It supports cross-play on supported platforms.

Pick the edition you own or that matches your devices. The core loop—break blocks, collect drops, craft, build—is the same idea on both.

## Game modes at a glance { .section}

Survival
:   You manage health, hunger, and inventory. Hostile mobs appear at night unless you sleep or stay well lit.

Creative
:   Unlimited blocks, flight, and no survival pressure—ideal for building experiments.

Peaceful \(Survival option\)
:   Survival mechanics without hostile mob spawns \(you can still take environmental damage in some situations\).
