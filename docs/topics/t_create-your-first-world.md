# Create your first world {#task_create_first_world .task}

Create a new single-player world with beginner-friendly settings.

For your first session, a Survival world on **Easy** or **Peaceful** difficulty reduces pressure while you learn movement and crafting.

1.  From the title screen, choose **Singleplayer**, then **Create New World**.

2.  Enter a world name you will recognize later.

3.  Set **Game Mode** to **Survival** \(or **Creative** if you only want to practice building\).

4.  Set **Difficulty** to **Peaceful** or **Easy** for a gentler start.

5.  Optional: open **More World Options** and leave bonus chest enabled if you want starter supplies near spawn.

6.  Choose **Create New World** and wait for terrain generation to finish.


You spawn in the world. Note your coordinates or build a simple landmark so you can find your first base after exploring.
