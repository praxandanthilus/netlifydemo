Install and launch Minecraft

Install the launcher for your edition, sign in, and open the game.

Steps depend on whether you use Java Edition or Bedrock. Use the path that matches your purchase.

  1. Download the official launcher for your edition from minecraft.net or your platform store (for example Microsoft Store or console store).
  2. Run the installer and sign in with the Microsoft account (or Mojang account, if still in transition) linked to your license.
  3. Open the launcher, select Minecraft, then choose Play to download updates if prompted and start the game.
  4. From the main menu, confirm you can reach Singleplayer, Multiplayer, and Options. You are ready to create or join a world.

Minecraft should be installed and able to launch. If sign-in fails, verify the account that owns the game and reset the password on the official site.
